# 使用指南

## 开始游戏

1. 在账号页登录 Microsoft 账号或创建离线账号。正版验证失败不会自动切换为离线身份。
2. 在下载页选择 Minecraft，可选 Forge、Fabric、NeoForge 或 Quilt，确认后安装。已有 `.minecraft` 可在设置中添加，NSCL 会识别其中的版本。
3. 在首页选择实例并启动。启动前检查账号、Java、目录可写性和磁盘空间，之后校验游戏文件与可用内存。
4. Windows 缺少匹配 Java 时，可在启动前检查窗口安装所需运行时并继续原启动任务。也可在设置中扫描或手动选择 Java。

Microsoft 刷新令牌保存在系统凭据库，访问令牌仅保留在内存；离线账号无法访问要求正版认证的服务器。账号页支持正版皮肤上传、3D 预览和披风选择。Linux 的凭据及运行时下载支持范围与 Windows 不同。

## 实例与启动设置

实例可使用独立目录、共享游戏目录，或沿用其他启动器的版本目录。整合包始终使用独立目录。切换目录模式不会搬移原存档或配置，共享目录会影响使用它的其他实例。

在实例概览点击「实例设置」，可单独配置 Java、内存及高级启动选项。高级选项默认继承全局设置；启用覆盖后，可指定窗口尺寸、全屏、附加 JVM 参数和游戏参数。**每行是一个完整参数**，同一参数中的空格保留，无需额外引号。账号身份和游戏目录由启动器管理。

实例设置中可填写分组并固定常用实例；固定实例在列表中优先显示，左侧可按分组筛选。Windows 可在实例概览「创建快捷方式」，保存新的 `.lnk` 到桌面等位置。快捷方式绑定游戏目录和实例 ID，打开后沿用已选择的游戏身份；缺少账号或 Java 时显示启动前检查，不会自行切换其他实例。

## 从其他启动器迁入

在实例管理点击「迁入已有实例」，填写来源 `.minecraft` 或游戏目录并扫描，选择来源实例：

- 「复用原目录」只添加并切换游戏目录，继续使用已有文件。
- 「预览复制到 NSCL」先展示实际来源、目标、文件数量和大小；确认后复制该实例的运行文件、所需资源与库，以及模组、配置、存档等内容，建立独立实例。账号、凭据、日志和下载缓存不复制。

复制前退出原启动器和游戏。来源与目标不能相同或互相包含；来源在预览后改变时需重新预览。目标已有相同运行文件会复用，已有不同内容的同名文件会阻止迁入。复制失败或取消不会发布新实例，也不会覆盖原目录。来源缺少运行依赖时请先在原启动器修复。

## 外置认证与本地皮肤

账号页的「外置认证」支持 Yggdrasil / authlib-injector。填写认证站提供的 HTTPS API 地址，先读取服务器信息，核对解析后的 API 地址后再使用该站的账号密码登录；有多个角色时可选择角色。账号按服务器地址、登录名和角色 UUID 区分，密码不保存。Windows/macOS 使用系统凭据库保存令牌；凭据库不可用时仅当前会话有效。

启动前刷新所选角色的凭据并检查身份，下载和验证 authlib-injector SHA-256，添加 Java agent 及可用的元数据预取参数。外置认证失败会停止启动，不会切换为 Microsoft 或离线身份。外置账号只能加入支持相应认证站的服务器。协议依据 [authlib-injector 启动器规范](https://github.com/yushijinhun/authlib-injector/blob/develop/wiki/src/en/launcher-technical-specification.md)。

离线账号可在皮肤页预览 PNG，保存为该账号的本地预览，或恢复默认预览。**本地预览只影响启动器内的角色展示**；游戏内及其他玩家看到的皮肤需要服务器、认证站或相应皮肤模组支持。Microsoft 皮肤上传和披风功能继续使用正版账号。

## 存档与截图

实例的「存档」页显示世界名称、文件夹、游戏版本、模式和最近游玩时间，并提供目录和「备份所有存档」入口。损坏或无法读取的 `level.dat` 会单独提示，不改写存档。存档备份仍按实例的 `saves/` 范围创建，可在「备份与复制」中恢复。

「截图」页按需加载缩略图，支持按文件名搜索、最近七天筛选和打开原图；大目录最多读取 1000 个条目。刷新可读取游戏运行期间产生的新截图。

## 主题与键盘

在设置的「外观与辅助功能」选择深色、浅色或高对比度主题，调整 75%–175% 界面缩放，或减少动画。修改即时预览，点击「保存设置」后保留。当前界面语言保持简体中文。

Tab / Shift+Tab 移动焦点，Enter / 空格激活控件。Ctrl+1 到 Ctrl+6 依次打开开始、实例、账号、下载、联机和设置；Ctrl+0 恢复 100% 缩放，F1 打开快捷键说明。

## Quilt 与 OptiFine

Quilt 可从下载页选择，支持 Quilt 整合包导入、升级、导出及已有 Quilt 配置识别。内容筛选使用项目声明的加载器，不保证所有 Fabric 模组自动兼容 Quilt。

Forge 实例概览提供「本地 OptiFine」。从 [OptiFine 官方下载页](https://optifine.net/downloads)获取匹配 Minecraft 的 JAR，保留官方文件名，并核对该构建标注的 Forge 兼容版本后确认导入。启动器会检查文件名中的游戏版本、JAR 标记及当前 Forge 版本是否改变；此检查不能替代真实运行兼容验证。其他加载器不使用这个导入流程。

备份、恢复、克隆和整合包回退见[实例备份说明](instance-backups.md)。游戏进程控制、实时日志和诊断见[故障排查](troubleshooting.md)。

## 内容来源与手动文件

下载页及实例模组搜索支持 Modrinth，并预留 CurseForge 接口。CurseForge API Key 由启动器内置配置提供，设置页无需填写。目前 Key 尚未配置，CurseForge 查询暂不可用，请先使用 Modrinth。API Key 不写入设置、任务记录或整合包。

CurseForge 作者限制第三方下载或 API 未返回下载地址时，启动器提供官方文件页面。下载指定版本后，在「手动补齐官方文件」填写 JAR / ZIP 的完整本地路径，点击「校验并补齐此文件」。大小和官方哈希一致后才缓存并用于安装，不根据文件编号猜测受限下载地址。没有 API Key 时无法查询 CurseForge 文件元数据。参见 [CurseForge API](https://docs.curseforge.com/rest-api/) 和[项目分发开关说明](https://support.curseforge.com/support/solutions/articles/9000207877)。

## 模组与本地资源

- 在实例模组页搜索兼容的模组，查看安装方案后确认；必需依赖一起解析，可选依赖由玩家决定。
- 「识别本地模组」将未登记 JAR 的 SHA-1 发给 Modrinth 查询，只发送哈希；确认结果后登记来源，不移动、替换或启用文件。无法识别的文件保留原状。
- 检查更新后勾选项目，点击「查看所选更新方案」统一预览并处理依赖。可锁定或解锁所选版本；锁定项目和整合包管理的模组不参加普通更新。
- 变更前可创建实例恢复点。批量更新默认选择该选项，确认前可查看依赖、文件变化和错误。
- 本地 JAR 可读取 Fabric、Quilt、Forge、NeoForge 元数据，并检查常见依赖版本约束。未知语法、条件依赖、嵌套组件及未识别模组会提示检查范围，不能保证任意模组组合运行正常。
- 资源包和光影页保留本地导入、禁用、启用与回收功能，并可从 Modrinth 在线搜索、选择兼容版本、安装和更新。已登记资源可查看在线版本；更新保留其启用状态。同名未登记文件或手动修改内容不会被直接覆盖。

资源移除后进入本地回收目录。游戏运行时锁定资源修改。光影效果仍需游戏内相应的光影支持。

## 整合包版本维护

支持 Modrinth `.mrpack` 和 CurseForge `manifest.json` ZIP。安装前检查清单、文件哈希、客户端范围及所需游戏和加载器；未知组件会明确提示。可选客户端文件在方案中选择。

在线安装的包保存来源项目和发布 ID。在实例概览打开「整合包升级与回退」，可选择在线版本或本地新版包，查看更新日志、文件变化及本地修改冲突，再确认升级。没有在线来源记录的旧包可用本地包受控升级。

升级前自动创建恢复点，保留存档、截图和游戏设置，保留玩家追加内容。本地修改默认保留，也可明确选择使用新版包文件替换。已登记追加模组或资源与新游戏版本不兼容时，会阻止升级并提示先处理。

在「备份与复制」中恢复升级前的完整实例快照，即可回到历史内容及运行配置。跨游戏版本恢复要求备份对应的游戏版本仍在本机安装；仅存档备份不能跨版本恢复。升级不删除共享客户端和依赖。

## 下载任务中心

下载页的「下载任务中心」显示当前任务和速度；文件提供总大小时会显示预计剩余时间。游戏版本及加载器安装有持久队列、历史状态和失败重试，可加入新任务并控制后续队列。重启后等待玩家点击「继续安装队列」，不会自动执行上次未完成的安装。

下载数据保存在 `.part` 和对应续传记录中。服务器支持时使用 Range 继续下载，并校验范围、资源标识和最终哈希；服务器不支持或数据不匹配时安全重下。取消或网络中断保留可续传数据，最终文件只有校验通过才发布。

「暂停当前任务」在任务的下载检查点生效；已发出的网络请求会按连接和读取超时结束。暂停后仍可取消任务。下载源可自动切换，默认跟随系统代理，也可在设置中选择直连。

## 联机

开房时填写本机对局域网开放或服务端的实际端口，也可点击「发现局域网世界」选择本机可连接的公告端口。加入房间前会比较游戏、加载器、整合包及模组摘要；发现差异或房主未提供摘要时，需要玩家确认。仅客户端模组不同也可能正常游戏，仍应遵守服务器要求。

当前运行实例的摘要不含账号、令牌或个人目录。环境比较最多检查 256 个模组，超限会说明范围。旧管理服务未提供摘要时保留加入能力，并提示手动核对；完整环境摘要功能需要服务端同步更新。

frpc、房间名额、服务部署与网络边界见[联机说明](multiplayer.md)。
