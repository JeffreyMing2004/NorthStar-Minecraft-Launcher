# NSCL 0.1.0-beta.1 · 首个公开测试版

面向 Windows 10 / 11 x86_64 的便携调试测试版。下载 `nscl-v0.1.0-beta.1-windows-x86_64-debug.zip`，完整解压到可写目录后运行 `NSCL.exe`。`SHA256SUMS` 提供压缩包的 SHA-256 校验值。

## 可测试功能

- Minecraft 安装、校验与修复，Forge / Fabric / NeoForge / Quilt 安装，以及本地 OptiFine 导入。
- Microsoft、外置认证与离线账号，皮肤预览、正版皮肤与披风管理。
- 独立实例、迁入、备份、恢复、克隆、存档与截图管理。
- Modrinth 模组、依赖、资源包、光影和整合包管理，本地文件导入与整合包升级回退。
- Java 下载与匹配、持久下载队列、日志诊断、主题、缩放和键盘操作。
- 联机房间、frpc 下载、局域网世界发现与环境比较。

## 本次完善

- 测试版可以发现并校验后续测试版更新，也可升级到更高的正式版；正式通道继续跳过测试版，不自动降级。
- 未启用的 CurseForge 来源在界面中禁用并说明原因，避免选择后才失败。
- 脱敏诊断包附启动器版本、系统架构和构建类型，方便复现测试问题。
- 增加调试便携包、使用说明、许可证、SHA-256 校验和测试反馈模板。

## 已知限制与后续工作

- CurseForge API Key 尚未配置，在线搜索、文件元数据查询和依赖该 API 的整合包安装暂不可用；请使用 Modrinth。
- 尚未完成真实 Microsoft 账号、全部游戏与加载器组合的端到端人工验收。自动测试不能保证所有模组组合兼容。
- 联机需可用服务、隧道配额及网络条件，公网不同运营商间的稳定性仍需测试反馈。
- 当前测试包仅提供 Windows x86_64 调试构建；没有安装器、签名和其他平台发布包。
- 离线账号皮肤仅用于启动器预览。软件渲染用于兼容性排查，性能较低。

首次测试建议使用独立游戏目录，操作已有实例前先备份。反馈入口：[GitHub Issues](https://github.com/JeffreyMing2004/NorthStar-Minecraft-Launcher/issues/new/choose)。请附复现步骤、版本信息及脱敏诊断包。
